# Research objectives

The review asks how to evaluate and improve the security of LLM-based agents across four dimensions:

1. **Attack** — prompt injection (including indirect), tool and API abuse, memory poisoning, retrieval poisoning, multi-agent manipulation, and data exfiltration through tools.
2. **Evaluation metrics and benchmarks** — what is measured, on what oracle, and whether the number matches the behavior.
3. **Mitigation and defense** — preventive, detective, responsive, and recovery controls, with residual risk. This dimension is the priority.
4. **Framework** — lifecycle, threat model, and test pipeline. The project’s own answer is AgentShield-LCE in `06_PROPOSED_FRAMEWORK/`, written as a synthesis rather than a rename of one paper.

The corpus is evidence for that design. A paper count is not the objective.
