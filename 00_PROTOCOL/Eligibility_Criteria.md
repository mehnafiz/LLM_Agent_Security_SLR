# Eligibility criteria

A row can be relevant and still be ineligible. These fields stay separate.

| Field | Verified only when |
|-------|--------------------|
| Publication type | Proceedings or journal record identifies the item as a full paper or article, not a workshop, poster, demo, or short paper |
| Venue quality | A dated JCR quartile, CiteScore quartile, or CORE/CCF rank is copied from a source we can point to. Absence of a license is recorded as Pending, not as a quartile |
| Indexing | The index entry was opened, not inferred from the publisher name |
| Relevance | The full text is about security of an LLM-based agent (tools, memory, or multi-agent), not only a generic LLM jailbreak or an agent used as a hacking tool against other software |
| PDF identity | The file’s title and authors match the row, and the file is not an arXiv-only copy presented as the version of record |
| Final eligibility | All of the above are Verified |

IEEE Xplore availability does not by itself prove venue quality. A workshop paper is excluded unless the eligibility rule is explicitly changed.

Preprint PDFs remain in the pending set. They are not moved into the eligible set to increase the count.
