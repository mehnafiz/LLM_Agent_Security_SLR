# Venue quality

No quartile is assigned in this consolidation.

| Evidence | Status |
|----------|--------|
| Journal Citation Reports | Not accessed. Do not read a blank cell as Q1–Q4 |
| Scopus CiteScore | Not accessed |
| CORE / CCF | Used only when a historical verification file already stored a rank. That rank is not upgraded and not invented |
| IEEE Xplore record | Proves an IEEE record exists. It does not prove a top-tier venue |
| ACL Anthology, NeurIPS proceedings, ICLR proceedings PDF host | Supports publication identity for that file. It is not a quartile |

Conference items are not labeled “main-track full paper” unless the proceedings page or a verification note says so. Workshop, poster, demo, and short-paper labels stay exclusion reasons when that label is in the source metadata (for example a title that begins with “Short Paper”).
